# 檜山大高家記 ／ 伝承帖

出羽国檜山郡（現・秋田県能代市檜山）を本拠とした**大高（おおたか／おおだか）氏**の家系調査の成果物。

| ページ | 中身 |
|---|---|
| [檜山大高家記](https://mochanwanwan.github.io/hiyama-otaka/) | 本編。同時代文書で確定した人物を、書状ごとに〈何をしていたか／原文／現代語訳〉で読む |
| [伝承帖](https://mochanwanwan.github.io/hiyama-otaka/yomimono.html) | 別巻。軍記・近世地誌・口碑を等級バッジ付きで集めたもの |

## このリポジトリについて

**公開ページを配信するためだけのリポジトリ**である。中身は自己完結した HTML 二つ。
調査の作業場（資料・典拠・誤りの記録・生データ）は**別の非公開リポジトリ**にあり、
このページはそこから `tools/build-site.sh` で生成して持ち込んでいる。

## 断り書き

- 典拠のないことは書いていない。推測は推測と明記している。
- 史料には等級を付けている（同時代文書／近世の写／近世地誌・自治体史／軍記／伝承・口碑）。
- 系統図の**赤い点線**は「まだ紙で裏づけていない関係」である。
- 青森県史デジタルアーカイブの画像は転載していない。閲覧ページへのリンクにとどめている。
